As of 2026-07-06 the user is planning a global-traffic supplement encyclopedia webapp ("영양제의 모든것" / Everything About Supplements) as a subdirectory of all-lifes.com, reusing the KoreaPlus architecture (static pages + JSON data + generator scripts + 9-language hreflang + PWA + Toss-style mobile tabs).

**Key decisions in the plan** (full doc: `C:\Users\juksu\supplements-webapp-plan.md`):
- YMYL/E-E-A-T compliance is the #1 constraint: every claim needs sources (NIH ODS primary), evidence-grade badges, medical disclaimer, editorial policy page.
- Content matrix: ingredients × goals × audiences × combinations (pair pages = N² long-tail).
- Killer feature: shareable supplement Interaction Checker widget (URL-param stacks).
- Language priority reversed vs KoreaPlus: en > ja > ko > … (English default).
- Monetization: iHerb affiliate main + Amazon/Coupang by region + light AdSense; no email capture (per [[cross-domain-growth-elements]]).
- User plans to hand implementation to Opus using the plan doc — Fable quota was low.
