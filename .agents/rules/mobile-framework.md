Mobile-first framework added 2026-06-27 (user wants a simple-but-practical Toss-like mobile web app). **Bottom tab bar** (`.kp-tabbar`, phones ≤768px only, hidden on desktop): Home / Explore / Search / Plan / Saved — fixed bottom, safe-area inset, active-tab highlight via a tiny pathname script. The **Search tab uses `data-action="search"`** which `modules/search.js` auto-wires to its ⌘K modal (search.js is loaded via header.js on hub pages, and the SEO shell loads it too). The **Explore tab** is `explore.html` which `localizeLinks()` rewrites to `<lang>/explore.html` on localized pages.

Two delivery paths (same markup + CSS):
- **SEO pages** (700+, via `build-seo.cjs` `shell()`): `tabBar(lang)` emits the bar with **localized labels** (`TABBAR` map, 9 langs); styles live in **seo.css ?v=9** (`.kp-tabbar` + a mobile block: 16px body / 1.75 line-height, 46px tap-target link pills, single-column cards, 2→1-up tiles, 16px filter input to avoid iOS zoom, body bottom-padding, back-to-top lifted above the bar).
- **Hub/info hand-pages** (12 hubs + about/contact/plan/privacy/terms): tab bar HTML injected before `</body>` (English labels); styles in **hub-styles.css ?v=10** (same `.kp-tabbar` block). deploy-seo.sh ROOTS now ships hub-styles.css + contact/plan/privacy/terms.

**Bottom sheet + swipe (2026-06-27):** reusable Toss-style bottom sheet in hub-styles.css (`.kp-sheet` / `.kp-sheet-trigger` / `.kp-sheet-panel` / `.kp-sheet-backdrop` / `.kp-sheet-handle` / `.kp-sheet-done`) — desktop renders inline, phones (≤768px) slide it up. Applied to **festivals.html** filters: a 🎚️ Filters button opens the sheet (city/type pills moved inside, reusing their existing listeners — no clone), close via backdrop/Done/Esc/**swipe-down** (touchmove on panel, only when scrollTop≤0, close if dy>90). festivals references **hub-styles.css?v=11**.

**Enhancement bundle `modules/kp-enhance.js` (2026-06-27, seo.css?v=10):** one defer-loaded module on every generated SEO page (all 9 langs) adding ~14 elements, each in try/catch, self-localizing from `<html lang>` (baked-in label map, no i18n dep): reading-time badge, native Share (Web Share API) + copy-link, Save/bookmark page (localStorage `kp_saved`), "On this page" scroll-spy TOC (sticky on mobile, built from h2s), smooth anchor scroll, Korean-name **TTS** (🔊 speechSynthesis ko-KR) + **copy** (📋) on the hero `.kr`, image **lightbox**, **resume-reading** (scroll % in `kp_read_<path>`), sticky mobile "Plan my trip" CTA (above tab bar), keyboard shortcuts (`/`→search via data-action, `t`→top), external-link hardening, toast. Wired in shell after install.js; shipped via deploy-seo.sh modules list. To add more: append a try/caught block in kp-enhance.js + its label to `T`.

**Task-first IA overhaul (2026-06-28, user: "app is confusing → make it simple like Toss"):** (1) Home **"Start here" grid** — 6 self-localizing task cards (Where to go→destinations / What to do→experiences / When to visit / Before you go→travel-basics / Plan my trip→plan / Search→data-action="search") injected in index.html right after .map-hero and ABOVE `#week-anchor` (week-section.js injects its carousel after that anchor — order matters). (2) Home mobile length 12,940→6,702px (−48%): `#content-grid` clamps to 1,500px via `.kp-clamp-grid` + localized Show-more (script near </body>, arms after 1.2s since app.js renders the grid async). (3) SEO-page mega-menu: `primaryNav(lang)` (build-seo.cjs) replaced the 3-dropdown PRIMARY_NAV with ONE localized "Explore ▾" dropdown — hub names from HUB_L10N per page lang, + All guides + K-Pop/K-Beauty/Blog group + Plan CTA; nav.js is generic so 1 dropdown works unchanged. hub-styles.css **?v=12** (kp-tasks/kp-clamp-grid). **GOTCHA (QA-caught live bug):** injecting inline JS through bash→node string layers double-unescaped `\\/` → `//(index.html)?$/` parsed as a comment → SyntaxError killing the whole inline script on 17 hand pages. When mass-injecting inline scripts, avoid regex literals with `/` (or parse-verify each file's script with `new Function(...)` after writing).

**Home simplification (index.html):** the long `#seo-article` SEO text wall collapses to 300px on mobile behind a localized "Read more" button (baked-in 9-lang map keyed off kp_lang) — content stays in the DOM (SEO-safe). Cut the mobile home ~12,940px → ~9,761px (−25%). index references hub-styles.css?v=11. CSS-only section-padding tweaks have little effect (length is content-driven), so the article collapse is the real lever.

**Do NOT add the travel tab bar to dispatch verticals** — index.html (home app shell), kpop.html, kpop-standalone.html, kbeauty.html have their own nav; they were accidentally hit by a broad inject-script once and reverted. When mass-editing root .html, EXCLUDE index/kpop*/kbeauty*. Also: the festival cards on festivals.html now fill missing TourAPI posters with keyword-matched Wikimedia images (`festFallbackImg`, gugak/lantern/mask/dance/hanbok/flower/food/market/fireworks/performance, EN+KR).
