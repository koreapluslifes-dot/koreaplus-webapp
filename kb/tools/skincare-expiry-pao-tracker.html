What is PAO?

PAO (Period After Opening) is how long a product stays good once opened — shown as a little open-jar symbol (e.g. 12M). Actives like vitamin C and sunscreen degrade faster, so the window is shorter.

How to use it

Pick the product type and the date you opened it; the tool returns the months it stays effective and the exact dispose-by date, so you never use a product that has turned.
